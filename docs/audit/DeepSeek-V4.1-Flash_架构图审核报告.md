## 三、已修正项（7 处）

### E1 【实质性错误】图中列入了 MTP 多 token 预测，但官方已将其移除

- **原图**：节点 15「MTP ×3 多 token 预测」，称「3 层多 token 预测头」。
- **官方口径**：V4.1-Flash **在主干预训练阶段取消 MTP**，改由独立训练的 DSpark 接管推测解码。原 MTP 与主干联合训练的路线已被替换。
- **风险**：把 V4.1 中不存在的组件作为架构特征展示，属于最典型的教学误导。
- **修正**：**删除该节点**。演示步数由 16 步调整为 15 步，OUTPUT 节点顺位为 15，行号 `d8` 及所有相关引用同步清理。

### E2 【实质性错误】DSpark 的两个参数被误读

| 原图表述 | 官方口径 | 判定 |
|---|---|---|
| 「专用专家：128 个路由专家」 | **128 是模块内的滑动窗口长度**（n_win = 128），不是专家数量 | 误读，已改 |
| 「只作用于最后 3 层」 | **由 3 个 Transformer block 组成的独立模块**，不作用于主干末尾 | 误读，已改 |

- **修正后**：明确「3 个 Transformer block 的独立模块」「一次前向并行给出 5 个草稿位置」「Markov 头建模草稿间依赖」「置信度头 + 调度器动态决定验证长度」「滑动窗口 128 token」「主干预训练后单独训练、梯度不回传主干」。

### E3 【结构性缺失 + 位置偏差】SWA 的归属

- **原图**：仅把「SWA Replay」画在解码器侧，暗示 SWA 是解码器某处的模块。
- **官方口径**（技术报告 Figure 3 原文）：*"The first two encoder layers use sliding window attention (SWA); the rest use Compressed Sparse Attention 2 (CSA2)"*；且 V4.1 **每一层都保留 SWA**，编码器前 2 层更是**只做 SWA**。
- **修正**：① 在编码器 CSA2 节点（04）中补充「前 2 层只做 SWA，第 3 层起进入 CSA2(m=2)」；② 将节点 11 重写为部署侧缓存策略，明确「每层都有 SWA」「n_win = 128」「编码器与解码器各有独立的 Bounded Replay 路径」。两处联动，避免把 SWA 读成某一层独有。

### E4 【表述错误】KV 投影桥并非「共享同一份 KV」

- **原图**：「全局 KV：20 个解码层共享一份」。
- **官方口径**：解码器各层的全局 KV 由编码器末层隐状态 H 投影得到，**每层有各自的投影权重 W_KV**。共享的是「底稿」（H），不是 KV 本身。
- **修正**：改为「逐层投影：每层有各自的投影权重 W_KV；共享底稿：全局 KV 同源于这一份隐状态」，并补一句关键澄清——**省掉的只是「每层各自生成全局 KV」，解码器 20 层本身仍要完整前向、各自计算 Q 与 SWA KV**（这是最容易被读错的地方）。

### E5 【规格偏差】Engram 的参数描述

| 原图表述 | 官方口径 | 判定 |
|---|---|---|
| 「16M 词表」 | 每个哈希头约 1600 万条目 | 表述模糊，已改 |
| 「8 头 × 256 维」 | 8 个哈希头，**每阶总嵌入维度 2048** | 换算而非官方口径，已改 |
| 未提及模块数量与位置 | **2 个模块，位于骨干第 1 层与第 14 层** | 缺失，已补 |

- **修正后**：补齐「{2,3,4} 阶 n-gram」「各阶表大小取互不相同的质数」「FP8 存储」「主机内存 RDMA 预取」「196B 不含在 552B 主干内」。

### E6 【限定条件缺失】FP4 只作用于全局主 KV

- **原图**：只说「主 KV 用 FP4（E2M1）」，未说明其余 KV 的精度。
- **官方口径**：**FP4 只量化全局主 KV；SWA-KV 对量化噪声更敏感，仍保持 FP8。**
- **风险**：学习者会误以为全部 KV 都被压到 4 bit。
- **修正**：节点 10 增加「SWA KV 保持 FP8」条目与正文说明。

### E7 【口径不完整】reasoning_effort 的可调范围

- **原图**：只写「reasoning_effort 1–100 连续调节」。
- **官方口径**：开源权重与 prompt 编码格式接受 1–100 整数；但**对外 API 目前只开放三档**：low = 50、high = 75、max = 100，默认 high。
- **修正**：补注 API 三档别名与默认值，并提示「写代码时以 API 文档为准」。

### 附带修正（非事实错误，属完整性补强）

- **ViT 节点（02）**：补充官方规格「32 层、hidden 1024、patch 14、downsample 3、单图 ≤1024 视觉 token、线性 patch 投影 + RMSNorm + SwiGLU」，并明确它是**与文本分支并联的旁路**，不是主干中的一层。
- **顶部指标行**：`552B 主干` → `552B 主干 + 196B Engram`，避免把总量误读为 552B。
- **图例**：`SWA Replay` → `SWA 有界重放`；`DSpark / MTP` → `DSpark 投机解码`。
- **2017 基线对照文案（A8）**：原写「V4.1-Flash 在此之前还插了 3 层 MTP 头」，随 E1 一并修正。
- **大白话讲解（PLAIN）**：与上述各项同步重写，共 6 条。
