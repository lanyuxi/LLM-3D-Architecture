## 二、实质性错误（2 处，均已修正）

### E1「思考不可关闭」被写成了通用属性

| 项 | 内容 |
|---|---|
| 图中原写 | 节点 13：「不支持关闭思考」「思考不能关闭」「官方模型卡写明：思考模式对所有交互都是必需的」 |
| 官方口径 | 这是**开放权重版**的属性。官方对托管版明确写：Qwen3.8-Max 是在权重之上「with more features, such as vision input & **non-thinking support**」。两者形态不同 |
| 严重性 | 图中**自相矛盾**——同一张图的节点 15 已经写了「托管版…增加了非思考模式」，节点 13 却说不能关闭 |
| 修正 | 节点 13 与大白话文案改为：**权重版不可关闭思考；托管版支持非思考模式** |

### E2 参数分项是未标注的第三方推算，且量级存疑

| 项 | 内容 |
|---|---|
| 图中原写 | 节点 09：「注意力约 23B、嵌入约 2B、共享专家约 4.6B，其余 2.3T 以上都是路由专家」 |
| 问题 | ① 这组数字没有官方来源，官方模型卡不给参数分项；②「注意力约 23B」经官方仓库张量形状核算量级不符（粗算约 38B）；③ 以陈述句写在 `d.how` 里，读者会默认是官方数字 |
| 修正 | 删除具体分项，改为**可由架构直接推出的定性结论**：「注意力、嵌入与共享专家这些非专家组件的参数量相对很小，2.4 万亿里绝大部分是路由专家承载的知识」。大白话文案同步 |

## 四、经核实确认无误的部分

**核心架构参数**（官方模型卡 + config.json + 官方仓库三源互证）：

- 2.4T 总参数 / 95B 激活；92 层；hidden 8,192；词表 248,320（官方标注 Padded）
- 隐藏布局官方公式：**23 × (3 × (Gated DeltaNet → MoE) → 1 × (Gated Attention → MoE))** → 69 线性 + 23 全局（**官方明确给出，非推算**）
- GQA：64 query / 4 KV 头，head dim 256，16:1
- `partial_rotary_factor = 0.25`、`rope_theta = 1e7`、RoPE 维度 64
- MoE：512 路由专家 + 1 共享，每 token 激活 10 路由（含共享共 11）；专家中间维度 2,048
- 激活率 3.96%、稀疏比约 25×
- 线性注意力 128 value 头 / 16 QK 头 / 卷积核 4
- MTP：`mtp_num_hidden_layers = 1`（层数来自 config，模型卡只写「multiple steps」）
- 上下文：原生 262,144 / 可扩展约 1,010,000 / 托管版默认 1M —— **三个口径归属均正确**
- 输出 131,072、推理 262,144
- `reasoning_effort` low / medium / xhigh，**默认 xhigh**（与官方一致；部分第三方误写为 high，本图未采用错误写法）
- `preserve_thinking` 默认开启
- **权重版纯文本、不支持多模态输入**（官方模型卡原文）vs **托管版增加视觉输入**——这是本图最扎实的一处区分
- 许可证为非 Apache 2.0 的自定义许可；「阿里首个开源 Max 级模型」为官方原话
- 嵌入层约 20 亿参数 / 占比约 0.08%（自洽计算，且 `tie_word_embeddings: false` 与输出头不重复计）

## 五、审核局限

3. **Qwen3.8 未见独立技术报告**：参数以模型卡 + config.json 为准。
4. **厂商自测口径**：性能数字均为官方自测，非第三方复现。
